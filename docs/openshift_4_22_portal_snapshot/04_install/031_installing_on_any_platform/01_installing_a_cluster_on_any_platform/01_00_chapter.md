# Chapter 1. Installing a cluster on any platform

In OpenShift Container Platform version 4.22, you can install a cluster on any infrastructure that you provision, including virtualization and cloud environments. 

Important

See "Deploying OpenShift 4.x on non-tested platforms using the bare metal install method" before you try to install an OpenShift Container Platform cluster in virtualized or cloud environments.
