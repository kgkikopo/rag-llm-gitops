# 13.1. Day 2 operations for OpenShift Container Platform clusters

You can use the following Day 2 operations to manage OpenShift Container Platform clusters. 

Updating an OpenShift Container Platform cluster
     Updating your cluster is a critical task that ensures that bugs and potential security vulnerabilities are patched. 
Upgrading OpenShift Container Platform clusters with RHACM and TALM
     You can use Red Hat Advanced Cluster Management (RHACM) and the Topology Aware Lifecycle Manager (TALM) to update spoke clusters that are managed from a hub cluster, including z-stream, y-stream, and EUS-to-EUS updates. 
Troubleshooting and maintaining OpenShift Container Platform clusters
     To maintain and troubleshoot a bare-metal environment where high-bandwidth network throughput is required. 
Observability in OpenShift Container Platform clusters
     OpenShift Container Platform generates a large amount of data, such as performance metrics and logs from the platform and the workloads running on it. As an administrator, you can use tools to collect and analyze the available data. 
Security
     You can enhance security for high-bandwidth network deployments by following key security considerations.
