# 1.3. Control plane machine management

As a cluster administrator, you can manage the control plane machines in your OpenShift Container Platform cluster. 

For example, you can perform the following actions: 

  * [Update your control plane configuration](https://docs.redhat.com/en/documentation/openshift_container_platform/4.22/html/machine_management/managing-control-plane-machines#cpmso-feat-config-update_cpmso-managing-machines "10.3.1. Updating the control plane configuration") with a control plane machine set for the following cloud providers: 

    * [Amazon Web Services](https://docs.redhat.com/en/documentation/openshift_container_platform/4.22/html/machine_management/managing-control-plane-machines#cpmso-config-options-aws "10.5.1. Control plane configuration options for Amazon Web Services")
    * [Google Cloud](https://docs.redhat.com/en/documentation/openshift_container_platform/4.22/html/machine_management/managing-control-plane-machines#cpmso-config-options-gcp "10.5.5. Control plane configuration options for Google Cloud")
    * [Microsoft Azure](https://docs.redhat.com/en/documentation/openshift_container_platform/4.22/html/machine_management/managing-control-plane-machines#cpmso-config-options-azure "10.5.3. Control plane configuration options for Microsoft Azure")
    * [Nutanix](https://docs.redhat.com/en/documentation/openshift_container_platform/4.22/html/machine_management/managing-control-plane-machines#cpmso-config-options-nutanix "10.5.7. Control plane configuration options for Nutanix")
    * [Red Hat OpenStack Platform (RHOSP)](https://docs.redhat.com/en/documentation/openshift_container_platform/4.22/html/machine_management/managing-control-plane-machines#cpmso-config-options-openstack "10.5.8. Control plane configuration options for Red Hat OpenStack Platform \(RHOSP\)")
    * [VMware vSphere](https://docs.redhat.com/en/documentation/openshift_container_platform/4.22/html/machine_management/managing-control-plane-machines#cpmso-config-options-vsphere "10.5.10. Control plane configuration options for VMware vSphere")

  * Configure and deploy a [machine health check](https://docs.redhat.com/en/documentation/openshift_container_platform/4.22/html/machine_management/deploying-machine-health-checks "Chapter 12. Deploying machine health checks") to automatically recover unhealthy control plane machines.
