# 1.7. Container tasks

Find procedures for working with Linux containers in an OpenShift Container Platform cluster. 

As an administrator, you can perform the following tasks on a Linux container: 

  * [Copy files to and from a container](https://docs.redhat.com/en/documentation/openshift_container_platform/4.22/html/nodes/working-with-containers#nodes-containers-copying-files "7.6. Copying files to or from OpenShift Container Platform containers"). 
  * [Allow containers to consume API objects](https://docs.redhat.com/en/documentation/openshift_container_platform/4.22/html/nodes/working-with-containers#nodes-containers-downward-api "7.5. Allowing containers to consume API objects"). 
  * [Execute remote commands in a container](https://docs.redhat.com/en/documentation/openshift_container_platform/4.22/html/nodes/working-with-containers#nodes-containers-remote-commands "7.7. Executing remote commands in an OpenShift Container Platform container"). 
  * [Use port forwarding to access applications in a container](https://docs.redhat.com/en/documentation/openshift_container_platform/4.22/html/nodes/working-with-containers#nodes-containers-port-forwarding "7.8. Using port forwarding to access applications in a container"). 



For Init containers, see [Init containers](https://docs.redhat.com/en/documentation/openshift_container_platform/4.22/html/nodes/working-with-containers#nodes-containers-init "7.2. Using Init Containers to perform tasks before a pod is deployed").
