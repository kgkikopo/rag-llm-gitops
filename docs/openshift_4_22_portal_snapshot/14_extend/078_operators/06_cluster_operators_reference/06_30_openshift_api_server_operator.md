# 6.30. OpenShift API Server Operator

The OpenShift API Server Operator installs and maintains the `openshift-apiserver` on a cluster. 

## 6.30.1. CRDs

  * `openshiftapiservers.operator.openshift.io`

    * Scope: Cluster 
    * CR: `openshiftapiserver`
    * Validation: Yes
