# 4.5. Adding components to an existing project

You can add components or services to an existing project from the **+Add** view in the **Developer** perspective. 

**Procedure**

  1. Navigate to the **+Add** view. 
  2. Click **Add to Project** ( ![odc add to project](https://access.redhat.com/webassets/avalon/d/OpenShift_Container_Platform-4.22-Building_applications-en-US/images/5b87d4a4a0268db0628c55650add180c/odc_add_to_project.png) ) next to left navigation pane or press `Ctrl`+`Space`
  3. Search for the component and click the **Start** /**Create** /**Install** button or click `Enter` to add the component to the project and see it in the topology **Graph view**. 

**Figure 4.2. Adding component via quick search**

![odc quick search](https://access.redhat.com/webassets/avalon/d/OpenShift_Container_Platform-4.22-Building_applications-en-US/images/7c30492bb9ab197bfab23cbafb38fa22/odc_quick_search.png) ![odc quick search](https://access.redhat.com/webassets/avalon/d/OpenShift_Container_Platform-4.22-Building_applications-en-US/images/7c30492bb9ab197bfab23cbafb38fa22/odc_quick_search.png)

Alternatively, you can also use the available options in the context menu, such as **Import from Git** , **Container Image** , **Database** , **From Catalog** , **Operator Backed** , **Helm Charts** , **Samples** , or **Upload JAR file** , by right-clicking in the topology **Graph view** to add a component to your project.
