# 1.1. Tutorials for developers

You can follow an end-to-end example of deploying an application on OpenShift Container Platform either by using the OpenShift CLI (`oc`) or the web console. 

Choose one of the following tutorials:

  * [Tutorial: Deploying an application by using the web console](https://docs.redhat.com/en/documentation/openshift_container_platform/4.22/html/tutorials/dev-app-web-console "Chapter 2. Tutorial: Deploying an application by using the web console")
