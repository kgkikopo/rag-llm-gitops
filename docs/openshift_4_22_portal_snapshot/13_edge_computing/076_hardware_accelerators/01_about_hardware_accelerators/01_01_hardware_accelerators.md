# 1.1. Hardware accelerators

Red Hat OpenShift Container Platform enables multiple hardware accelerators. 

The following hardware accelerators are enabled by Red Hat OpenShift Container Platform: 

  * NVIDIA GPU 
  * AMD Instinct® GPU 
  * Intel® Gaudi®
